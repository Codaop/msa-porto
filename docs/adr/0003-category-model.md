# Category model: three craft categories, no filler

Projects are grouped into exactly three craft categories — Software, Design, Media — and nothing else. UI/UX is not a category: it appears only as a facet inside Software projects. Organizations, extracurriculars, and volunteering live on a single Experience page rather than as project categories. Education is a short homepage listing.

The rule that matters: no category or project exists to "fill up" the portfolio. Filler work dilutes the signal for hiring managers and produces conversations about the wrong skills. The boundaries are deliberate — a future contributor might reasonably add a UI/UX category or convert Experience into a project category, and this decision records why they should not.
