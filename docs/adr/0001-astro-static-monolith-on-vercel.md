# Astro static monolith deployed to Vercel

The portfolio is a static monolith: Astro with project content as Markdown content collections, built to zero-JS-output HTML and served by Vercel's free tier. No backend, database, or auth anywhere in the system. This keeps maintenance near zero and matches the "simple monolith" scope the repo was created for — despite the directory name, this is not a microservices architecture.

The Kali aesthetic was considered as a reason to switch frameworks; it is achievable with hand-written CSS/JS and does not require one.
