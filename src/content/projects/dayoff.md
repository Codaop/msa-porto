## The problem

A class assignment to build a leave management ecosystem covering four distinct user roles, with a deadline tight enough that delivery discipline mattered as much as the features.

## What I did

- Designed and developed the UI for all 4 roles: Web Admin, Web HR, Mobile Employee, and Mobile Manager
- Served as UI/UX Designer, Frontend Engineer, and Mobile Engineer in an 8-person team
- Applied Agile practices, daily stand-ups, and Git version control to keep the team moving together

## Results

The team delivered the full ecosystem within the deadline, with each role's interface tailored to how that user actually works.
