## The problem

The seminar organizers wanted to see several visual directions before committing to a single poster.

## What I did

- Produced three variants of the same seminar poster: a bold type-driven version, a minimal line-art version, and a photo-based version
- Kept the typographic hierarchy identical across variants so the organizers could compare tonal direction, not layout quality
- Delivered final files in print (A4, 300 dpi) and screen (Instagram, 1080 px) sizes

## Results

The organizers picked the type-driven variant, and the same layout system was reused for the rest of the semester's sessions.
